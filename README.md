                  Лабораторна робота №1 — Домен і модель даних (ER)
Домен

Обраний домен — онлайн-магазин.

Система призначена для зберігання інформації про покупців, товари, категорії товарів, замовлення та оплати.

                             Основний сценарій роботи

1)Покупець створює замовлення.

2)Замовлення містить одну або декілька позицій товарів.

3)Кожна позиція визначає товар, кількість і ціну товару на момент замовлення.

4)Товар належить до певної категорії.

5)Для замовлення може бути створена оплата.

                                    Основні сутності

Customer — покупець.

Product — товар.

Category — категорія товарів.

Order — замовлення.

OrderItem — окрема позиція замовлення.

Payment - інформація про оплату замовлення.

                                     Мета моделі

Побудувати концептуальну ER-модель даних онлайн-магазину з коректними:

-сутностями;

-атрибутами;

-первинними ключами;

-зовнішніми ключами;

-зв'язками;

-кардинальностями

Модель не є фізичною схемою бази даних і не містить SQL DDL або ORM-коду.
