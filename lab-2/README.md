
# Лабораторна робота №2 — Вимоги та Use Cases

## Use Case Diagram

**Вихідний код діаграми:** [use-case.puml](use-case.puml)

Діаграма описує взаємодію користувачів з онлайн-магазином.

**Актори:**
- Користувач
- Покупець
- Адміністратор

Покупець і адміністратор є спеціалізованими ролями користувача. Платіжний сервіс є зовнішньою системою, з якою онлайн-магазин взаємодіє під час оплати.

**Use Cases:**
- UC01 — Переглянути каталог
- UC02 — Переглянути товар
- UC03 — Оформити замовлення
- UC04 — Оплатити замовлення
- UC05 — Додати товар
- UC06 — Оновити статус замовлення
- UC07 — Завершити покупку

**Зв'язки на діаграмі:**
- Узагальнення акторів: Покупець і Адміністратор успадковують роль Користувача.
- `extend`: UC02 «Переглянути товар» розширює UC01 «Переглянути каталог».
- `include`: UC07 «Завершити покупку» включає UC03 «Оформити замовлення».
- `include`: UC07 «Завершити покупку» включає UC04 «Оплатити замовлення».
